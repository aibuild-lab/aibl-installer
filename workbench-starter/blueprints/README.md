# blueprints

Plans your agent can follow, one file each. A blueprint is a numbered list of steps in plain words, with what "done" looks like at the end.

To run one, say: follow `blueprints/<name>.md`. Your agent reads the file and does the steps in order, asking you only where the file says to ask.

Nothing is here on day one. You add your first one in lesson 8, and you write your own the same way. If you did something by hand twice, it wants to be a blueprint.
