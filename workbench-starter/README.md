# my-workbench

Your AI Build Lab workbench: one private folder where your agent keeps what it knows about you, reads what you hand it, and follows the plans you keep. The AI Build Lab installer made it. Everything you make with your agent lives here, and it has a private copy on GitHub under your name.

Three folders, three jobs:

- `context/` what your agent knows about you. You write it and correct it; your agent reads it first, every session.
- `library/` things you hand your agent to read: transcripts, articles, documents.
- `blueprints/` plans your agent can follow, one file each.

`CLAUDE.md` and `AGENTS.md` are the note your agent reads before every session (Claude reads the first, Codex the second; they say the same thing). The skills that came with the workbench are in `.claude/skills/` and `.agents/skills/`.

The name is yours. Rename this folder and this repository whenever you like; it is a hub, not a brand.
